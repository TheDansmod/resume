    \begin{itemize}[leftmargin=*]
        \item \textbf{Agentic workflow}: Designed a LangGraph state machine with 8 specialised nodes (human-in-the-loop input, request quantifier, intent planner, vision analyser, item-description generator, tool-using retrieval agent, critic, explainer) and conditional routing. Every LLM call is held to a Pydantic output schema.
        \item \textbf{Multimodal retrieval}: Built text-to-image semantic search over the 260k-item FashionGen catalogue using named image and text vectors in Qdrant (on-disk HNSW and payload, category-filtered queries). Migrated embeddings from a GPU-hosted Marqo-FashionSigLIP model to managed Amazon Nova Multimodal Embeddings on Bedrock so the pipeline could run in the cloud.
        \item \textbf{Data pipeline}: Restructured a 14 GB HDF5 dataset into an S3-native layout: 260k images sharded under S3 prefixes by parallel extract-and-upload workers, plus item metadata as zstd-compressed Parquet loaded into an in-memory lookup. Wrote a resumable embedding and upsert job (point ID = dataset index) and generated JSONL inputs for Bedrock batch inference.
        \item \textbf{MCP tool server}: Exposed the catalogue as LLM tools (semantic search, category listing, item lookup returning text plus image content) through a custom FastMCP server over streamable HTTP. A pluggable tools-client interface switches by config between remote MCP tools and in-process tools, so the agent can be tested without the server.
        \item \textbf{Production readiness}: Built a Chainlit chat UI that streams per-node progress in real time, with AWS Cognito OAuth sign-in and chat history persisted to DynamoDB and S3. Added a swappable LangGraph checkpointer layer (SQLite, Postgres, DynamoDB with TTL, compression and adaptive retries) for multi-turn session resume. Wrote a provider-agnostic model factory (Bedrock, Mistral, Gemini, Ollama) with client-side rate limiting. Everything is wired through a dependency-injection container with typed Pydantic config, structured JSON logs, LangSmith tracing and per-session token-cost tracking. Persistence resources are defined as CloudFormation nested stacks.
        \item \textbf{Evaluation and testing}: Curated a 60-query evaluation set (50 image+text, 10 text-only) across 5 request types: complementary pairing, style variation, body-type fit, aesthetic-from-image and free-text. Built a rubric-based LLM-as-a-judge pipeline that scores visual grounding, per-item suitability and request coverage with weighted aggregation: 9.1 ± 0.3/10. Added an async integration test that runs the full graph with mocked LLMs and agents, with coverage reporting.
    \end{itemize}
