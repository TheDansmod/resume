    \begin{itemize}[leftmargin=*]
        \item Building a high-throughput game-solving engine for a Tinyhouse chess variant, targeting full-game resolution via exhaustive breadth-first search (BFS) over the reachable state space followed by retrograde (backward-induction) analysis from terminal positions.

        \item Diagnosed memory-mapped-file storage as a write-throughput bottleneck for the BFS visited-state table; designed and implemented a sharded log-structured-merge (LSM) storage engine with an in-memory write buffer and streaming, memory-mapped-file-based compaction to sustain the required write throughput within a constrained disk budget.
        \item Benchmarked the LSM design against RocksDB as an off-the-shelf alternative; RocksDB's generic per-key overhead (block indices, bloom filters, compression metadata) produced both lower sustained write throughput and disk-footprint overhead exceeding the available budget, motivating a workload-specific storage engine exploiting fixed-width, bitboard-derived keys.
    \end{itemize}
